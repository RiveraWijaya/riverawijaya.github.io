# Project images

Drop project images in this folder. The filename must match the project's `id` in `site-data.js`.

Examples:

- `fsk-modem.jpg`
- `minitpu.png`
- `uart-i2c.webp`
- `adcs-firmware.jpg`
- `class-e-pa.png`
- `buck-boost.webp`

Supported lowercase extensions: `.jpg`, `.jpeg`, `.png`, `.webp`, `.avif`, and `.svg`.

If a project has no matching file, its page automatically hides the image area.
